# 中文字体

- `wushan-serif.ttf`：Noto Serif SC，600 字重，Google Fonts 中文字符子集。标题用宋体。
- `wushan-script.ttf`：Ma Shan Zheng，Google Fonts 宣传短句子集。装饰短句用手写体。
- 正文使用设备自带的苹方、微软雅黑等中文无衬线字体。

字体通过 Google Fonts 官方 CSS text 子集接口取得，保留原始字体内部命名；文件仅改本地文件名。按 SIL Open Font License 1.1 分发，完整许可见同目录的两个 OFL 文件。未包含的字符回退到设备中文字体；页面不请求第三方字体服务。

来源：https://github.com/google/fonts/tree/main/ofl/notoserifsc 与 https://github.com/google/fonts/tree/main/ofl/mashanzheng 。
